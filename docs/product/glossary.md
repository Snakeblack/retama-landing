# Glosario

| Término | Definición |
| --- | --- |
| Retama | Marca de la empresa: ingeniería de software y soluciones informáticas, 100 % online |
| Lead cualificado | Contacto de una empresa con un proyecto real que llega por formulario, reserva, email o WhatsApp |
| Isla | Componente interactivo que hidrata solo él dentro de una página que, por lo demás, es HTML estático |
| Mejora progresiva 3D | Cadena de presentación de la escena: GPU moderna → API gráfica compatible → imagen estática. Ningún nivel es imprescindible para el contenido |
| DESIGN.md | Archivo de la raíz con los tokens de diseño (YAML) y su justificación (prosa). Es la única fuente de verdad visual |
| Presupuesto de rendimiento | Umbrales de `scenario:perf-mobile` que el CI verifica |
| Preview | Despliegue efímero de una rama que no es `main` |
| ADR | Architecture Decision Record, en `docs/architecture/decisions/` |
| Skill vendorizada | Skill de agente copiada en `.claude/skills/`, fijada a un commit y auditada |
| Bandeja de respaldo | Segunda dirección de email que recibe una copia de cada lead |
